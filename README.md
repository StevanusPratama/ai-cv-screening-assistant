🤖 AI CV Screening Assistant (Gemini Opal Workflow)

📌 Overview

AI CV Screening Assistant adalah mini automation berbasis Gemini Opal untuk membantu HR melakukan screening CV secara otomatis dan efisien.


🎯 Tujuan Project

* Mengurangi waktu screening manual
* Meningkatkan efisiensi rekrutmen
* Membantu HR mengambil keputusan


👥 Target Pengguna

* HR (Human Resources)
* Recruiter
* Perusahaan & Startup

⚙️ Cara Kerja

CV → Input Job Description → AI Analisis → Output → HR Review

📊 Output

* Match Score
* Ringkasan kandidat
* Rekomendasi (Layak / Dipertimbangkan / Tidak Cocok)
